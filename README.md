# Huggingface_AI

## Hugging Face Pipelines

Huggingface_AI is a simple AI web application developed using Python, Streamlit, and Hugging Face Transformers.

The application performs four Natural Language Processing (NLP) tasks using pre-trained AI models.

## Live Demo

**Try the application here:**

https://huggingfacepipelines-tc7fdfvhl3mu2bzizscnfs.streamlit.app/

## Features

### 1. Text Summarization

Converts long paragraphs into short summaries.

### 2. Translation

Translates English text into French.

### 3. Sentiment Analysis

Identifies whether the given text expresses a positive or negative sentiment.

### 4. Question Answering

Answers questions based on the context provided by the user.

## Technologies Used

* Python
* Streamlit
* Hugging Face Transformers
* PyTorch

## Installation

Install the required packages:


pip install -r requirements.txt


## Run the Application


python -m streamlit run app.py
